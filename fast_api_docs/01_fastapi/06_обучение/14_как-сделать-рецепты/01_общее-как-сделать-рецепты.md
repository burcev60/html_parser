## Оптимизация производительности ответа — Модель ответа — Возвращаемый тип

Чтобы оптимизировать производительность при возврате JSON-данных, используйте возвращаемый тип или модель ответа; таким образом Pydantic выполнит сериализацию в JSON на стороне Rust, без прохождения через Python. Подробнее читайте в документации: [Руководство — Модель ответа — Возвращаемый тип](https://fastapi.tiangolo.com/ru/tutorial/response-model/) ([local](./../06_учебник-руководство-пользователя/17_модель-ответа-возвращаемый-тип.md)).
