## Data Management Integrations

Integration| Description  
---|---  
[Airbyte](https://qdrant.tech/documentation/data-management/airbyte/) ([local](./data-management/airbyte.md))| Data integration platform specialising in ELT pipelines.  
[Airflow](https://qdrant.tech/documentation/data-management/airflow/) ([local](./data-management/airflow.md))| Platform designed for developing, scheduling, and monitoring batch-oriented workflows.  
[Chonkie](https://qdrant.tech/documentation/data-management/chonkie/) ([local](./data-management/chonkie.md))| No-nonsense, ultra-light and lightning fast RAG pipelines library.  
[CocoIndex](https://qdrant.tech/documentation/data-management/cocoindex/) ([local](./data-management/cocoindex.md))| High performance ETL framework to transform data for AI, with real-time incremental processing  
[Connect](https://qdrant.tech/documentation/data-management/redpanda/) ([local](./data-management/redpanda.md))| Declarative data-agnostic streaming service for efficient, stateless processing.  
[Confluent](https://qdrant.tech/documentation/data-management/confluent/) ([local](./data-management/confluent.md))| Fully-managed data streaming platform with a cloud-native Apache Kafka engine.  
[DLT](https://qdrant.tech/documentation/data-management/dlt/) ([local](./data-management/dlt.md))| Python library to simplify data loading processes between several sources and destinations.  
[Fluvio](https://qdrant.tech/documentation/data-management/fluvio/) ([local](./data-management/fluvio.md))| Rust-based platform for high speed, real-time data processing.  
[POMA](https://qdrant.tech/documentation/data-management/poma/) ([local](./data-management/poma.md))| Python library for data ingestion, and structured chunking from various sources.  
[Spark](https://qdrant.tech/documentation/data-management/spark/) ([local](./data-management/spark.md))| A unified analytics engine for large-scale data processing.  
[Unstructured](https://qdrant.tech/documentation/data-management/unstructured/) ([local](./data-management/unstructured.md))| Python library with components for ingesting and pre-processing data from numerous sources.
