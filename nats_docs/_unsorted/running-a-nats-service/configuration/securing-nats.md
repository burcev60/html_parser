# Securing NATS

The NATS server provides several forms of security:

  * Connections can be [_encrypted_ with TLS](https://docs.nats.io/running-a-nats-service/configuration/securing_nats/tls) ([local](./securing-nats/tls.md))

  * Client connections can require [_authentication_](https://docs.nats.io/running-a-nats-service/configuration/securing_nats/auth_intro) ([local](./securing-nats/auth-intro.md))

  * Clients can require [_authorization_](https://docs.nats.io/running-a-nats-service/configuration/securing_nats/authorization) ([local](./securing-nats/authorization.md)) for subjects they publish or subscribe to
