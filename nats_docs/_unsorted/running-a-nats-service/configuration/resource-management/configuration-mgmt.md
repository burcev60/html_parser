# Configuration Management

In many cases managing the configuration in your application code is the best model, many teams though wish to pre-create Streams and Consumers.

We support a number of tools to assist with this:

  * [CLI with Configuration Files](https://docs.nats.io/running-a-nats-service/configuration/resource_management/configuration_mgmt/nats-admin-cli) ([local](./configuration-mgmt/nats-admin-cli.md))

  * [Terraform](https://docs.nats.io/running-a-nats-service/configuration/resource_management/configuration_mgmt/terraform) ([local](./configuration-mgmt/terraform.md))

  * [GitHub Actions](https://docs.nats.io/running-a-nats-service/configuration/resource_management/configuration_mgmt/github_actions) ([local](./configuration-mgmt/github-actions.md))

  * [Kubernetes JetStream Controller](https://docs.nats.io/running-a-nats-service/configuration/resource_management/configuration_mgmt/kubernetes_controller) ([local](./configuration-mgmt/kubernetes-controller.md))
