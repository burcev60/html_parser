## About the data

[](<https://pydantic.dev/docs/validation/latest/pydantic-people/pydantic_people/#about-the-data> ([local](./pydantic_people.md#about-the-data)))

The data displayed above is calculated monthly via the Github GraphQL API (see [source code](<https://github.com/pydantic/pydantic/tree/main/.github/actions/people/people.py>), many thanks to [Sebastián Ramírez](<https://github.com/tiangolo>) for the script from which we based this logic).

Depending on changing conditions, the thresholds for the different categories of contributors may change in the future.
