# 🕷️ scrape_by_crawl.py

Рекурсивный скрапер документации с обходом ссылок (BFS) и сохранением страниц в `.md`.  
Умеет извлекать структуру навигации из сайдбаров и сохранять файлы в логичном порядке:  
`01_get-started/01_welcome-to-pydantic.md`.

---

## ✨ Возможности

| Фича | Описание |
|------|----------|
| 🔗 **Универсальный парсер навигации** | Работает с MkDocs, Docusaurus, Starlight, VuePress, Mintlify и другими. Извлекает порядок разделов из сайдбара. |
| 📁 **Slug-имена файлов** | `01_welcome-to-pydantic.md` — нижний регистр, дефисы, числовые префиксы для сортировки. |
| 🔄 **Fallback на URL** | Если навигацию не удалось извлечь — структура папок строится по пути из URL. |
| 🔗 **Перелинковка** | Ссылки на скачанные страницы автоматически заменяются на локальные (`[текст](./02_setup.md)`). Якоря внутри страницы остаются как `#anchor`. |
| 🛡️ **Три бэкенда** | `requests` (стандарт), `curl_cffi` (обход Cloudflare), `playwright` (рендеринг JS для SPA). |
| ⚡ **Оптимизация загрузки** | Блокировка тяжёлых ресурсов (картинки, шрифты, аналитика) в режиме Playwright. |
| ♻️ **Resume-режим** | Пропускает уже скачанные файлы при повторном запуске. |
| 📦 **Frontmatter** | Каждая страница получает заголовок с `title` и `source` для отслеживания происхождения. |

## 📦 Установка

```bash
# Обязательные зависимости
pip install requests beautifulsoup4 html2text brotli

# Опционально: для обхода Cloudflare
pip install curl_cffi

# Опционально: для сайтов с динамическим контентом (JS)
pip install playwright
playwright install chromium
```

> 💡 **Совет:** Скрипт принудительно использует IPv4. Если ваш провайдер не поддерживает IPv6 — проблем не возникнет.

## 🚀 Быстрый старт

```bash
# Базовый запуск (бэкенд requests)
python scrape_by_crawl.py \
  --start https://pydantic.dev/docs/ \
  --output ./pydantic_docs

# С обходом Cloudflare
python scrape_by_crawl.py \
  --start https://example.com/docs \
  --output ./output \
  --backend curl_cffi

# Для сайтов с динамическим контентом (React, Vue, Astro)
python scrape_by_crawl.py \
  --start https://astro.build/docs \
  --output ./astro_docs \
  --backend playwright

# С ограничением и паузой между запросами
python scrape_by_crawl.py \
  --start https://docs.example.com \
  --output ./docs \
  --max-pages 500 \
  --delay 1.0
```

---

## ⚙️ Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--start` | **Обязательный.** Стартовая страница документации. | — |
| `--output` | Папка для сохранения `.md` файлов. | `./docs_md` |
| `--max-pages` | Максимальное количество страниц для скачивания. | `2000` |
| `--delay` | Пауза между запросами в секундах (для вежливости). | `0.3` |
| `--backend` | HTTP-бэкенд: `requests`, `curl_cffi`, `playwright`. | `requests` |
| `--resume` | Пропускать уже существующие файлы (продолжить прерванную загрузку). | `False` |

## 📂 Структура выходных файлов

```
./output/
├── 01_get-started/
│   ├── 01_welcome.md
│   ├── 02_installation.md
│   └── 03_quickstart.md
├── 02_concepts/
│   ├── 01_models.md
│   └── 02_validation.md
├── 03_api/
│   └── 01_base_model.md
└── _unsorted/          # Страницы, не найденные в навигации
    └── api-reference.md
```

> 📌 Файлы получают префиксы `01_`, `02_`… в порядке, в котором они встречаются в сайдбаре. Это сохраняет иерархию при сортировке по имени.

## 🔗 Как работает перелинковка

После скачивания всех страниц скрипт делает второй проход и заменяет ссылки:

| Исходная ссылка | После обработки |
|-----------------|-----------------|
| `https://pydantic.dev/docs/concepts/models/` | `[Models](./02_concepts/01_models.md) ([local](./02_concepts/01_models.md))` |
| `https://pydantic.dev/docs/concepts/models/#field-types` | `[Field types](#field-types)` |
| Ссылка на уже скачанную страницу | Добавляется пометка `([local](...))` рядом с оригинальной ссылкой |

> ✅ Это позволяет легко перейти на локальную копию, но не ломает оригинальную ссылку, если локальный файл отсутствует.

## 🛠️ Решение частых проблем

### ❌ Ошибка `DNS не резолвит` или `Нет TCP-соединения`
- Проверьте подключение к интернету.
- Убедитесь, что домен доступен из вашей сети.
- Если сайт блокирует запросы из вашего региона — попробуйте `--backend curl_cffi` или VPN.

### ❌ Cloudflare / защита от ботов
```bash
python scrape_by_crawl.py --start https://example.com --backend curl_cffi
```

### ❌ Сайт не загружается, пустые файлы
Скорее всего, контент рендерится на клиенте (React/Vue/Astro). Используйте Playwright:
```bash
pip install playwright && playwright install chromium
python scrape_by_crawl.py --start https://example.com --backend playwright
```

### ❌ Неправильный порядок файлов
- Убедитесь, что стартовая страница содержит сайдбар с навигацией.
- Если навигация не распознаётся — файлы сохранятся в `_unsorted/` по структуре URL.
